# Sistema de Medición de Lluvia

Aplicación de escritorio desarrollada en C# y .NET para la gestión y análisis de mediciones de lluvia.

## Descripción

Proyecto académico desarrollado en equipo para la materia Programación Orientada a Objetos de la carrera de Ingeniería en Sistemas.

El sistema permite registrar y consultar mediciones de lluvia, administrar usuarios y permisos, generar alertas y realizar diferentes operaciones sobre la información registrada.

## Tecnologías

- C#
- .NET
- Windows Forms
- Programación Orientada a Objetos
- Archivos CSV

## Funcionalidades

- Registro y consulta de mediciones de lluvia.
- Consulta de mediciones por localidad.
- Consulta de mediciones por rango de fechas.
- Cálculo del total acumulado de agua.
- Identificación de la localidad con mayor registro de lluvia.
- Generación de alertas por exceso de lluvia entre mediciones consecutivas.
- Gestión de usuarios y roles.
- Administración de familias y permisos.
- Recuperación de contraseña.
- Registro de eventos mediante bitácora.
- Generación de copias de seguridad.
- Envío de notificaciones por SMS/WhatsApp.
- Envío de solicitudes mediante correo electrónico.
